# AuthNova — Login Authentication System

A modern, responsive login and registration system developed as part of the **OASIS INFOBYTE Web Development & Designing Internship**.

## Project Overview

AuthNova is a front-end authentication project built with HTML, CSS, and JavaScript. It provides a clean user interface for account registration, login, and a protected dashboard.

## Features

* User registration with form validation
* Login using registered account details
* Duplicate account detection
* Password confirmation validation
* Password hashing with the Web Crypto API
* Remember Me functionality
* Session management
* Protected dashboard access
* Logout functionality
* Responsive design for desktop, tablet, and mobile
* Modern dark UI with blue and purple gradients

## Technologies Used

* HTML5
* CSS3
* JavaScript
* LocalStorage
* SessionStorage
* Web Crypto API

## How to Run

1. Download or clone the repository.
2. Open the project folder in Visual Studio Code.
3. Open `index.html` in your browser, preferably using the Live Server extension.
4. Register an account, log in, and explore the dashboard.

## Important Security Note

This project is intended for educational purposes. Authentication data is stored in the browser, so it is not suitable for production use. A real authentication system should use a secure backend, server-side validation, and appropriate password storage.

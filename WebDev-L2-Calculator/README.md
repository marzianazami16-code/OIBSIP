# OIBSIP Level 2 - Calculator

A modern and responsive calculator developed as part of the OASIS Infobyte Web Development and Designing Internship Program.

## Project Overview

This project is a functional calculator built using HTML, CSS, and Vanilla JavaScript.

The calculator provides a clean and modern interface with responsive design and supports basic mathematical operations.

## Features

- Addition
- Subtraction
- Multiplication
- Division
- Percentage
- Decimal numbers
- Clear button
- Delete button
- Division-by-zero protection
- Chained calculations
- Keyboard support
- Responsive design
- Modern gradient UI
- Smooth animations and transitions

## Technologies Used

- HTML5
- CSS3
- Vanilla JavaScript

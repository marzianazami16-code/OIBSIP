# ✨ TaskFlow — Premium To-Do Web App

A modern, responsive, and interactive To-Do Web Application developed as part of the **OASIS INFOBYTE Web Development & Designing Internship — Level 2, Task 3**.

TaskFlow helps users organize daily tasks, manage priorities, track deadlines, and monitor productivity through a clean, futuristic interface.

## 🚀 Features

### 📋 Task Management

* Add new tasks with a title, priority, category, and due date.
* Edit existing tasks.
* Mark tasks as completed or pending.
* Delete tasks when they are no longer needed.
* Display pending and completed tasks separately.

### 📊 Advanced Statistics

* Track pending, completed, and total tasks.
* View overall progress and completion rate.
* Count unfinished high-priority tasks.
* Identify tasks due within the next 24 hours.
* Track the number of unique categories in use.

### 🔎 Productivity Tools

* Search tasks by text.
* Filter tasks by status.
* Sort tasks by creation date, priority, or due date.
* View task creation and completion timestamps.
* Save tasks locally using browser `localStorage`.

### 🎨 UI & Design

* Modern dark interface with vibrant gradient accents.
* Glassmorphism-inspired cards and visual effects.
* Smooth hover interactions and transitions.
* Responsive layout for desktop, tablet, and mobile.
* Light/dark theme support.

## 🛠️ Technologies Used

* **HTML5** — Application structure
* **CSS3** — Styling, layouts, gradients, animations, and responsive design
* **JavaScript** — Task management, filtering, sorting, statistics, and local storage
* **Font Awesome** — Icons
* **Google Fonts** — Typography

## ▶️ How to Run

1. Clone or download this repository.
2. Open the `WebDev-L2-ToDoWebApp` folder.
3. Open `index.html` in your browser.
4. Start adding and managing your tasks.

No build tools or package installation are required.

## 💾 Data Storage

TaskFlow uses the browser's `localStorage` to save tasks and theme preferences locally. Tasks remain available in the same browser unless its stored site data is cleared.
